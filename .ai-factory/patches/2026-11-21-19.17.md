# Fixture __pycache__ broke pinned HEAD reproducibility

**Date:** 2026-11-21 19:17
**Files:** benchmarks/fixtures.py, benchmarks/fixtures/trees/**, tests/benchmarks/test_fixtures.py, docs/cli.md, docs/architecture.md, benchmarks/baselines/*
**Severity:** high

## Problem

Offline e2e and benchmark fixture materialization raised
`FixtureError: head_mismatch` for all seven cases. Pinned
`expected_head` values no longer matched freshly materialized Git
commits after `__pycache__/*.pyc` appeared under
`benchmarks/fixtures/trees/`. Stale CLI docs still claimed the
workflow was unwired and `workflow.max_retries` was reserved. Baseline
JSON referenced missing per-case `*.metrics.json` files.

## Root Cause

`_copy_tree` copied every file under the fixture source tree into the
temporary Git repo. Importing or running Python against those trees
left bytecode beside sources; those cache files entered the commit
and changed the tree hash. Docs from earlier milestones were only
partially rewritten during v1-08, leaving contradictory “not wired”
sections. Per-case baseline metrics were never retained after the
aggregate capture.

## Solution

- Deleted polluted `__pycache__` directories from fixture trees.
- Skipped cache/bytecode paths in `_copy_tree` (`__pycache__`,
  `.pytest_cache`, `*.pyc`, etc.) with `[FIX]` skip logging.
- Added a regression test that plants `__pycache__` beside sources and
  asserts the pinned HEAD still matches.
- Added a static inventory guard
  (`test_fixture_trees_have_no_bytecode_inventory`) so CI fails if
  `__pycache__` / `*.pyc` reappear under `benchmarks/fixtures/trees/`.
- Corrected `docs/cli.md` / `docs/architecture.md` to describe the
  wired workflow and active `workflow.max_retries`.
- Regenerated `benchmarks/baselines/v1-offline-baseline.json`, the
  human summary, and the seven linked metrics reports (7/7).

## Prevention

- Never import fixture tree modules in-process without isolating
  bytecode (`PYTHONDONTWRITEBYTECODE=1`) or keeping trees read-only.
- Materializers must exclude VCS/cache/build noise even when source
  trees look clean.
- Keep a static inventory assertion on fixture trees in CI.
- Review docs for leftover “not wired / reserved” language when a
  milestone lands public CLI behavior.
- Persist linked baseline artifacts together; do not leave dangling
  `metrics_path` references.
