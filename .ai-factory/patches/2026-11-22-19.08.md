# Verification drift: missing docs cross-link and edge-case packing tests

**Date:** 2026-11-22 19:08
**Files:** docs/context-retrieval.md, tests/context/test_packing_session.py, tests/context/test_packing_expansion.py, tests/context/packing_support.py, tests/context/test_packer.py, tests/providers/test_deepseek_packed_context.py
**Severity:** low

## Problem

Post-implementation verification reported two non-blocking gaps:

- `docs/context-retrieval.md` was listed in the plan's docs rollout but was not
  updated to link the new packing surface.
- Several ultra edge cases existed in implementation code but lacked dedicated
  tests: incomplete-scan missing witness, mutation during final revalidation,
  dependency direction mismatch, and missing/wrong delivery receipt variants.

## Root Cause

The implementation batch covered primary behavior and the mandatory docs page,
but treated the retrieval page as already-sufficient context. Edge-case tests
focused on primary statuses and budgets; adversarial revalidation and delivery
receipt variants were verified only through adjacent code paths.

## Solution

- Added a retrieval/packing boundary note and navigation link to
  `docs/context-retrieval.md`.
- Added session tests for an incomplete scan that cannot verify a recorded
  witness and for a witness mutation during final revalidation.
- Added expansion tests for dependency direction/anchor mismatch and delivery
  rejection of unknown receipts, extra carry-forward IDs, closed sessions, and
  source mutation before delivery.
- Removed function-local test imports to keep the project import rule.

No runtime behavior or production logging changed.

## Prevention

- When a plan enumerates docs files, update every listed page or record an
  explicit reason for leaving one unchanged.
- For stateful APIs, add at least one adversarial test per transition hazard:
  incomplete evidence, final-witness change, receipt identity, carry-forward
  mismatch, and session closure.
- Run the full offline suite after adding edge-case tests, not only the new
  modules.
