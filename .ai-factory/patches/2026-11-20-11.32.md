# Default orchestrator seam did not share the gateway usage ledger

**Date:** 2026-11-20 11:32
**Files:** src/lean_weave/app.py, tests/test_app_context.py, .ai-factory/ROADMAP.md
**Severity:** low

## Problem

Verification of v1-06 left two non-blocking warnings:

1. `create_orchestrator` passed `journal=None` to the workflow budget when the
   caller did not inject one, even though it constructed a default
   `JsonlMetricsCollector` for `DeepSeekProvider`. `WorkflowBudget.feature_spend()`
   therefore fell back to the local control record instead of the gateway ledger,
   contrary to the plan's requirement to use the existing ledger as the
   production source for feature-wide spend.
2. `.ai-factory/ROADMAP.md` still marked CodeExecutor + VerificationRunner as
   incomplete although `executor/` and `verify/runner.py` are implemented.

## Root Cause

The accounting journal was resolved separately inside `create_llm_provider`.
The orchestrator had its own `journal` argument with a `None` default, so the
default construction path produced two independent views of spend. The roadmap
was not refreshed when the code-tools milestone completed.

## Solution

- Resolve one `accounting` value in `create_orchestrator`: an explicit
  `journal` wins, then an injected `metrics_collector`, then the default JSONL
  journal when the production provider will be constructed.
- Pass that same object to both `create_llm_provider` and
  `MinimalWorkflowOrchestrator`, so gateway admission and workflow feature
  spend read one ledger. Injected/Mock providers without a journal retain the
  local fallback.
- Added a test asserting the constructed provider and orchestrator share the
  identical `JsonlMetricsCollector` and that construction still performs no
  journal I/O.
- Marked CodeExecutor + VerificationRunner complete in the roadmap with its
  implementation date.

## Prevention

- Resolve shared accounting dependencies once at the composition root; do not
  let each factory default independently.
- Assert object identity for shared ledgers, not only object type.
- Refresh roadmap checkboxes when a milestone's implementation is committed.

## Regression Evidence

The new identity test fails against the previous seam (`orchestrator._journal`
was `None`) and passes after the change. Full offline suite: 497 passed,
1 skipped. Construction still leaves `.lean-weave/metrics/` absent.
